layer; `scripts/port_closure.py`), `riscv-lean/`, `Tcc/Boot/` (cut interface).
The captured cut of P = `c/tests/p3/sum.c` (`Tcc/Capture/Sum/`, generated by
`scripts/tcc_cut.py` + `scripts/gen_tcc_cut.py`): `TccSumCut` (GPRs, PC =
`tcc_baremetal_enter`, `GoodState`, the 6,689-byte partial view the program
phase reads, empty console), `cut_ok` (satisfiable), host bytes checked equal
