# Attribution

The whole-compiler project's C semantics is based on
**[Cerberus, by the Cambridge REMS team](https://github.com/rems-project/cerberus)**
and **[cerberus-lean, by Mike Dodds / Oath](https://github.com/OathTech/cerberus-lean)**.
Cerberus supplies the C semantics and reference frontend; cerberus-lean supplies
the Lean translation, handwritten execution layer, proofs and validation gates
that we import and extend as CSem. These are upstream contributions, not work
originating in ship-your-tcc. Exact pins, licences and local adaptations follow.

This repository reuses the machinery of ship-your-interpreter
(BasisResearch/ship-your-interpreter) through its most advanced copies,
ship-your-lua and ship-your-ocaml (all Basis Research). Third-party
components keep their own licences.

The F1 image-filesystem fork (`CerbFS`, Lem driver/runtime proxies and
`Tcc/CSem/FsModel.lean`) builds on the imported Cerberus / REMS semantics and
cerberus-lean / Mike Dodds / Oath runtime. Its image-specific behavior is
derived from this repository's `c/src/htif.c`; it was recovered from the prior
agent worktree and reviewed with descriptor-based fstat, structural ordering
and link proxy repairs. See `results/csem/f1-filesystem.md`. This is an
executable model and differential evidence, not a reused library proof.

`Spec/ImageFiles.lean` reuses this fork's existing `CerbFS.embed` and
`CerbFS.resolve` directly for ordered embedded tables and preprocessing
lookup, and exports the same initialized tree to `Tcc/ModelMain.lean`.
This factors executable behavior derived from `c/src/htif.c`; it copies no
library proof and does not establish filesystem refinement.
The 2026-10-27 repin evaluation reuses upstream's current proofs, outcome protocol,
quotation definitions and Boolean-conversion repairs. Our total stop encoding
shares one field description between the existing JSON value and total wire
rendering, reusing Lean's `Lean.Json.renderString` (Apache-2.0, Lean contributors).
Exact pins, patch dispositions and limitations are in
`results/csem/repin-2026-10-27.md`; the frozen `sum.c` proof artifacts were not changed.
