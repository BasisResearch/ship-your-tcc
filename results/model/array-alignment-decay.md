# Array alias alignment at pointer decay

The repair clears only an array alias's outer alignment metadata when the
compiler derives a pointer. Array/referent metadata, qualifiers, size, bounds,
address-taking and unevaluated array queries remain independently represented.
CSem stays C11 with the approved GNU extensions; Supported/Fits is unchanged.
No sum compile cuts are regenerated.

## Source audit

`array_decay_alignment` in patch 0003 and `Tcc.Model.Types` has the same guard:
`VT_ARRAY | VT_VLA`. It resets `aligned` alone. Each caller keeps its original
tag conversion; the helper neither rewrites nor mutates the reference graph.

| C action | Lean mirror | reason |
|---|---|---|
| `gen_op`, pointer +/- integer | `Gen2.gen_op` | convert the saved array type before restoring the result |
| `gen_cast`, final target copy | `Gen2.gen_cast` | conditional/common-array results derive a pointer |
| `convert_parameter_type` | `Gen3.convert_parameter_type` | array/VLA parameter adjustment already reset alignment; factor the same rule |
| `save_reg_upstack`, array address spill | `Gen1.save_reg_upstack` | the saved value becomes a pointer lvalue |
| RV64 `gfunc_call`, argument classification | `Riscv.gfunc_call_classify` | actual array arguments become pointer values, including variadic calls |

All explicit array-bit removal sites in the executed `tccgen.c` and
`riscv64-gen.c` closure were audited. `mk_pointer` remains responsible for
new pointer derivation: it stores the entire incoming CType as referent and
clears the outer alignment. `indir` restores the complete referenced CType.
`combine_types` may carry an array type until `gen_cast`; the final conversion
clears its outer alignment. Ordinary aligned pointer aliases do not satisfy
the array guard and retain their alignment through arithmetic.

Array declarator construction and `typeof(a)`/`sizeof(a)` never perform this
conversion. Existing invalid-element checks run before parameter adjustment;
clearing derived metadata cannot make an invalid element array admissible.
The vendor tree is untouched; source copies and image are regenerated by
`scripts/tcc_src.sh` and `c/Makefile`.
